# Mayur Chinni — Portfolio Website

A responsive, one-page professional portfolio for an Agile Delivery Lead / Scrum Master profile.

## Preview locally
Extract the ZIP and open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in or create a free account at https://github.com/
2. Create a **public** repository named `mayur-portfolio` (or any name you prefer).
3. Upload `index.html` to the repository root and commit.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. After publishing, GitHub Pages will show your shareable URL, typically `https://YOUR-USERNAME.github.io/mayur-portfolio/`.

GitHub Pages is free for public repositories. A custom domain is optional and would require a domain you own.

## Before publishing
Edit `index.html` and replace:
- `YOUR_EMAIL@example.com` with your professional email.
- `https://www.linkedin.com/` with your exact LinkedIn profile URL.
- Any case-study details you want to make more precise or cannot substantiate in an interview.

## Privacy and accuracy
Case studies are generalized. Do not add confidential customer information, internal screenshots, company-only metrics or details you are not authorized to share. Add only verified outcomes.
